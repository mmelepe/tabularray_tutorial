# Tabularray tutorial 

This repository offers a non-official tutorial for the tabularray package. There are two different versions:

* A detailed, beginner friendly tutorial: [Learning tabularray](https://raw.githubusercontent.com/mmelepe/tabularray_tutorial/master/latest.pdf). A [French translation](https://zestedesavoir.com/tutoriels/5029/les-tableaux-en-latex-avec-tabularray/) is available.
* A compact version of the same tutorial: [tabularray by example](https://raw.githubusercontent.com/mmelepe/tabularray_tutorial/master/latest_compact.pdf)

It is aimed at beginners, so no preliminary knowledge of latex tables is required. 

Contributions welcome.
