Multipage tables are defined with the \snippet{longtblr} environment. Its horizontal alignment can be defined with \snippet{halign} (default is \snippet{c}) and is automatically included as a floating table element. The \snippet{caption} and \snippet{label} are defined as outer attributes. 

To repeat rows at the beginning and end of the table on each page, use \snippet{rowhead} and \snippet{rowfoot}. You can repeat more than 1 row at the beginning or end. The repeating row(s) at the bottom must be written at the end of the table.

Continuation text can be personalized in the \snippet{default} templates of tabularray (otherwise the default values apply). You can also use named templates, see the documentation for more details. 

Long tables are significantly slower at compilation than normal tabularray tables, which themselves are significantly slower at compilation than native Latex tables. Do not use longtblr if the table can fit on one page.
